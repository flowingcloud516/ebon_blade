# 对话记录规则

> **文档定位**：讨论记录目录使用说明。
>
> **主要作用**：说明外部、内部和摘要记录的归档位置及脱敏规则。
>
> **使用方式**：新增或整理AI对话前阅读；正式实现仍以设计文档为准。

`talk/`保存人与AI的讨论过程，用于追溯需求和决策原因；正式实现依据仍然是`design/`和源码目录中的`*_design.md`。

## 目录

- `external/<year-month>/`：外部环境中的脱敏讨论记录。
- `internal/<year-month>/`：只存在于内网仓库的敏感讨论记录。
- `summaries/`：供新AI快速接手的阶段状态。

## 规则

1. 原始讨论按日期追加，不修改用户原始回答。
2. 稳定结论必须同步到正式设计。
3. 外部记录不得包含真实地址、凭据、内部命令和敏感日志。
4. 历史讨论中的旧方案可以保留，但新AI不得把它当成当前设计。
5. 当前设计入口见根目录[AGENTS.md](../AGENTS.md)。
